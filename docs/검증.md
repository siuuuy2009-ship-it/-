# 검증 기록

- 양쪽 정점 0~4개의 모든 74,963개 이분 그래프에서 앱의 최대 매칭 결과와 독립 완전탐색 최댓값 비교 통과
- 같은 물품·신청자 중복 없음, 유효 간선만 선택됨, 순차 배정 이상의 건수 검사 통과
- 자기 물품·상태·거리 필터, 중복 신청 병합, 삭제·취소, 확정·전달된 양쪽 정점 보존 검사 통과
- API를 통해 자료 저장·다시 읽기, 작업 공간 분리, 잘못된 요청 거부, 충돌 감지, 전달 완료 흐름 검사
- 별도 검토에서 발견한 ‘동시 수정 충돌 후 오래된 확인창 유지’ 문제 수정: 충돌 시 대화상자를 닫고 최신 자료를 불러옴
- TypeScript 검사, 정적 검사와 프로덕션 빌드 수행

브라우저 화면 클릭·시각 검수는 별도로 수행하지 않았습니다. WebMCP를 지원하는 검증 환경이 없어 해당 도구의 브라우저 등록·실행은 검증하지 않았습니다. 일반 UI와 API 사용에는 필수 기능이 아닙니다.

테스트는 알고리즘과 구현의 정해진 동작을 검증합니다. 실제 학교 사용성, 공정성, 전달 완료율을 검증한 실험은 아닙니다.
