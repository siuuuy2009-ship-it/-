# 다시, 나눔

기숙사에서 **필요한 건 부탁하고, 여유 있는 건 나누는** 학생용 앱입니다.

같은 기숙사에 필요한 물건을 가진 친구가 있어도 누가 무엇을 나눌 수 있는지 알기 어렵습니다. ‘필요해요’에 부탁 글을 올리고 ‘나눠요’에 물품을 등록하여 서로 돕습니다. 신청이 모이면 **최대 이분 매칭**으로 가능한 많은 학생에게 물품을 배정합니다.

## 사용하기

- [앱](https://dasi-nanum.vercel.app/)
- [가상 학생 6명의 시연](https://dasi-nanum.vercel.app/?demo=classroom)
- 학생은 운영자가 배부한 초대코드로 안내에 동의한 뒤 가입합니다.
- 필요한 물건은 ‘필요해요’에 올립니다. 친구가 실제 물품을 등록하면 받을 수 있는 후보를 선택해 신청합니다.
- 배정은 운영자가 확인·확정하고 실제 전달 완료를 기록합니다.
- 전달 후 당사자가 매너 평가를 할 수 있습니다. 점수는 기본 50점, 평가에 따라 +2/0/-2점이며 0~100점으로 제한합니다.
- ‘다음 나눔 이어가기’는 전달이 끝난 배정을 정리하고 남은 물품·미배정 신청·부탁 글을 보존하여 계속 이용하게 합니다.

## 최대 이분 매칭

왼쪽은 물품 한 개, 오른쪽은 신청자 한 명입니다. 신청자가 선택한 물품이며 상태 조건을 충족하고 자기 물품이 아닐 때만 연결합니다. 한 사람이 여러 물품을 나눌 수 있으므로 나눔자 자체를 왼쪽 정점으로 사용하지 않습니다.

DFS 증가 경로 탐색으로 확정 전 임시 배정을 재조정합니다. 참고서 A·B 모두 가능한 학생과 A만 가능한 학생이 함께 신청했다면 A를 후자에게, B를 전자에게 배정하여 둘 다 받게 할 수 있습니다. 가상 시연에서는 순차 배정 3명, 최대 이분 매칭 6명이 나옵니다. 매너 점수는 배정 기준에 사용하지 않습니다.

한 배정에서 신청자는 최대 한 개, 각 물품은 최대 한 사람에게 배정됩니다. 핵심 탐색은 O(VE)입니다. 최대 건수를 보장하지만 선호 순위나 대기 이력까지 최적화하는 것은 아닙니다. 부탁 글은 게시판 자료이며 실제 등록 물품에 대한 신청과 구분됩니다.

## 개발과 검증

Node.js 24와 pnpm 11.19.0을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
pnpm lint
pnpm build:vercel
node scripts/preview-school.mts
```

Vercel은 Vite/React 화면과 Node.js API를 제공하며 Supabase PostgreSQL에 학교 자료를 저장합니다. DATABASE_URL은 서버 환경변수로 설정하고 비밀번호·학생 명단·초대코드를 소스에 넣지 않습니다. 가상 시연은 브라우저 메모리에서만 동작합니다.

기존 로컬 전용 판은 pnpm db:local 후 pnpm dev로 실행합니다. Windows 실행파일의 로컬 자료와 온라인 학교 자료는 별개입니다. pnpm desktop:build와 scripts/package-windows.ps1로 패키징하며 GitHub Actions의 Windows executable 작업도 사용할 수 있습니다.

자세한 가입·동의·계정 삭제 안내는 [학생 로그인](docs/학생-로그인.md), 설명용 대본은 [발표](docs/발표.md)를 참고하세요.
