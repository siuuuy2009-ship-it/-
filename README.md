# 다시, 나눔

학교 공동 나눔 행사에서 **최대 이분 매칭**으로 가능한 한 많은 학생에게 물품을 배정하는 앱입니다.

> 첫 버전은 **행사 운영자용 MVP**입니다. 운영자가 참여자·물품·신청을 입력하고 일괄 배정합니다. 학생별 로그인, 여러 기기에서 같은 행사를 공동 편집하는 기능은 포함하지 않습니다.

## 무엇이 다른가요?

물품 게시판에서 개별 거래를 성사시키는 것에 더해, **같은 회차의 물품과 신청을 모두 고려한 배정**을 다룹니다. 민수는 참고서 A·B 모두 가능하고 지수는 A만 필요한 경우, A를 민수에게 먼저 배정하면 한 명만 받습니다. A→지수, B→민수로 조정하면 두 명 모두 받을 수 있습니다.

## 주요 기능

- 참여자와 활동 구역 등록, 물품 이름·종류·상태·수령 구역·설명 등록
- 한 사람이 여러 물품을 신청하고 최소 상태·최대 이동 거리 지정
- 물품 검색과 종류 필터, 신청 수정·취소, 물품 삭제
- 동일 입력에 대한 순차 배정과 최대 이분 매칭 비교
- 신청 마감 → 배정 미리보기 → 확정 → 전달 완료
- 확정 배정 보존, 전달 전 취소, 취소한 연결의 재배정 방지
- 미배정 신청자 안내와 확정 결과 CSV 다운로드
- 단계별 이분 그래프 설명과 예시 행사 불러오기
- 서버 저장, 작업 공간 분리, 동시 변경 충돌 감지
- Windows 실행파일 빌드 및 GitHub Actions 자동 검사

## 바로 시연하기

처음 열면 **가상 물품 6개, 참여자 7명(신청자 6명)**이 들어 있습니다.

1. **나눔 물품**에서 물품 종류와 상태를 확인합니다.
2. **참여자·신청**에서 어떤 물품을 신청했는지 확인합니다.
3. **자동 매칭**에서 순차 배정 **3명**, 최대 이분 매칭 **6명**을 비교합니다.
4. **신청 마감**을 누르고 **배정 확정**을 누릅니다.
5. 실제로 물품을 전달한 경우에만 **전달 완료**로 표시합니다.
6. **알고리즘 이야기**에서 2권의 책·2명의 학생 예제를 단계별로 보여 줍니다.

실제 행사 자료를 입력하려면 **새 행사**를 누릅니다. 현재 자료를 대체하므로 필요한 배정 결과는 먼저 내려받아 주세요.

## 개발 실행

필요 환경: Node.js **24 LTS**, pnpm **11.19.0**.

```sh
git clone https://github.com/siuuuy2009-ship-it/-.git dasi-nanum
cd dasi-nanum
corepack enable
corepack prepare pnpm@11.19.0 --activate
pnpm install --frozen-lockfile
pnpm db:local
pnpm dev
```

표시되는 `http://localhost:3000` 주소를 엽니다. 로컬 실행에는 Cloudflare 계정이나 외부 데이터베이스가 필요하지 않습니다. 로컬 D1 자료는 `.wrangler/state/`에 저장됩니다.

```sh
pnpm test           # 74,963개 작은 그래프의 완전탐색 대조 + 업무 규칙 검사
pnpm typecheck      # TypeScript 검사
pnpm test:api       # 개발 서버 실행 중 API·저장·충돌 검사
pnpm build          # 웹 배포 빌드
```

`pnpm-workspace.yaml`은 의존성의 설치 스크립트를 실행하지 않도록 설정합니다. 지원 환경의 사전 빌드된 실행 바이너리를 사용합니다.

## Windows 실행파일

`DasiNanum.exe`를 실행하면 앱 화면이 기본 브라우저에서 열립니다. **Node.js나 Python을 별도로 설치할 필요가 없습니다.** 함께 열린 작은 창을 닫으면 로컬 서버가 종료됩니다. 인터넷 연결 없이 등록·신청·매칭을 사용할 수 있습니다.

- 자료 위치: `%LOCALAPPDATA%/DasiNanum/nanum.sqlite`
- 실행 로그: `%LOCALAPPDATA%/DasiNanum/app.log`
- 실행파일은 로컬 컴퓨터의 `127.0.0.1`에서만 연결을 받습니다.
- 웹 배포판과 실행파일의 자료는 별개입니다.

직접 빌드하려면 Windows, Node.js 24, Python 3.14가 필요합니다.

```sh
pnpm install --frozen-lockfile
pnpm desktop:build
python -m pip install -r desktop/requirements.txt
```

그다음 PowerShell에서 실행합니다.

```powershell
./scripts/package-windows.ps1
```

결과는 `artifacts/DasiNanum.exe`와 `artifacts/DasiNanum-Windows.zip`에 만들어집니다. GitHub **Actions → Windows executable → Run workflow**로도 빌드할 수 있습니다. 완료된 실행의 **Artifacts**에서 내려받을 수 있습니다. 실행파일 자체는 Git에 넣지 않습니다.

## 알고리즘과 규칙

- 왼쪽 정점: **물품 한 개**. 한 사람이 여러 개를 나눔할 수 있으므로 나눔자 자체를 정점으로 쓰지 않습니다.
- 오른쪽 정점: **신청자 한 명**. 같은 사람이 여러 번 신청해도 하나의 정점입니다.
- 간선: 신청한 물품이며, 자기 물품이 아니고, 상태·거리 조건을 충족하는 경우
- 목표: 회차당 **물품 1개에 최대 1명, 사람 1명에 최대 1개** 조건에서 배정 수 최대화
- 구현: DFS 증가 경로 기반 Kuhn 알고리즘. 시간 복잡도 `O(VE)`, 보조 공간 `O(V+E)`이며 화면 시연용 단계 기록에는 추가 공간을 사용합니다.
- 이미 확정·전달된 물품과 신청자는 제외한 다음 나머지만 계산합니다. 이때 최댓값은 **기존 확정을 유지하는 조건에서의 최댓값**입니다.

최대 매칭은 선호 순위, 공정성, 가장 가까운 사람 우선을 보장하지 않습니다. 순차 배정과 결과가 같은 입력도 있습니다. 배정 가능 건수와 실제 전달 완료 건수는 구분합니다.

## MVP의 범위

- 운영자가 실제 사람을 한 번씩 등록해야 합니다. 이름의 중복을 막지만 실명 인증은 하지 않습니다.
- 거리 조건은 교내의 미리 정한 **본관↔후관 200m, 본관↔기숙사 500m, 후관↔기숙사 400m**입니다. GPS 측정 거리가 아닙니다. 학교에 맞게 `lib/domain.ts`의 거리표를 바꿀 수 있습니다.
- 행사당 물품·참여자는 각각 최대 80개·80명입니다.
- 자료는 서버 데이터베이스에 저장하고, 브라우저의 HttpOnly 쿠키가 작업 공간을 식별합니다. 다른 브라우저는 별도 공간이며, 쿠키를 지우면 기존 공간에 다시 접근할 수 없습니다. 계정 로그인·복구 기능은 후속 과제입니다.
- 사진 업로드, 채팅, 학생별 계정, 푸시 알림, 실시간 공동 편집은 포함하지 않습니다.
- WebMCP가 지원되는 브라우저에서는 자료 읽기·매칭 미리보기·신청 저장 도구를 등록합니다. 미지원 브라우저에서는 일반 화면으로 사용합니다.

## 온라인 배포

웹 서버는 Cloudflare Workers 호환 출력과 D1 데이터베이스를 사용합니다. `.openai/hosting.json`에는 Sites 프로젝트의 공개 식별자와 논리 바인딩만 있습니다. 비밀번호나 배포 토큰은 포함하지 않습니다. GitHub에 푸시하는 것과 웹앱을 호스팅하는 것은 별도 단계입니다.

이 저장소를 자신의 Sites 프로젝트로 배포하려면 자신의 프로젝트 식별자와 D1 바인딩을 설정한 뒤, 스키마 마이그레이션과 `pnpm build` 결과를 배포하세요. 데스크톱 버전은 Sites 계정 없이 사용합니다.

## 코드 구조

| 경로                         | 역할                                          |
| ---------------------------- | --------------------------------------------- |
| `lib/matching.ts`            | 최대 이분 매칭·순차 배정 비교                 |
| `lib/domain.ts`              | 상태, 조건 필터, 신청·확정·취소 규칙          |
| `app/nanum-app.tsx`          | 웹·데스크톱에서 함께 쓰는 한국어 화면         |
| `app/api/workspace/route.ts` | 웹 저장·동시 변경 감지 API                    |
| `db/`, `drizzle/`            | D1 스키마와 마이그레이션                      |
| `desktop/`                   | 오프라인 UI 진입점·SQLite 서버·Windows 실행기 |
| `tests/`                     | 완전탐색 대조 및 업무 규칙 검사               |
| `docs/발표.md`               | 간단 발표 대본과 시연 순서                    |

이 프로젝트는 교육용 알고리즘 과제에서 출발했습니다. 테스트를 통과한 범위와 현재의 서비스 범위를 구분하여 발표해 주세요.
